# Optional Plugin packaging

The first stable GitHub group candidate uses a flat member-directory layout. The retained exporter can separately assemble these four scientific members under `skills/` for a future Plugin candidate. A Plugin export is a distinct derived artifact requiring current official schema validation and platform review; a GitHub candidate does not establish marketplace availability.

Run `python scripts/export_release_candidate.py --help` for the bounded metadata interface. The exporter refuses existing destinations and checks its exact four-member assembly, privacy-safe root files and checksums. It never creates or pushes a remote repository. Plugin submission is outside this grouping task.
