# Verification scope for 1.1.0

The grouping preparation checks exact membership and unique ownership, stable metadata, official Skill frontmatter, UI invocation fields, Python syntax, local Markdown links, selected private-path/credential patterns and retained licenses. Maintainer checks bind each independently copied candidate, its SHA256SUMS and ZIP member bytes to the reviewed source inventory. Historical candidate files remain unchanged; derived selection indexes can point to the new candidate.

Available synthetic regressions are run against both source and an independent candidate copy. Environment-dependent skips are reported separately. The exact run counts and artifact identities are maintained with this release preparation; no historical total is presented as the count for this reorganized group.

Full clean-session implicit activation, cross-discipline behavioral evaluation and real long-context recovery were not rerun for this group. The recorded scoring regressions use synthetic transcripts and test the scorer, not future model behavior.

Version 1.0.0 identifies the chosen first stable public contract. It does not turn a structural pass or a limited synthetic check into universal behavioral, scientific, visual, legal or security proof. GitHub creation, push, tag and Release are separate from local candidate preparation. No plugin marketplace or other distribution platform was submitted during this grouping work.
