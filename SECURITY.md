# Security Policy

## Supported Versions

Security and privacy fixes target the latest published release. Development snapshots are not supported releases and may change before publication.

## Reporting

Use the repository's private GitHub security-advisory channel for suspected credential exposure, path traversal, unsafe archive handling, privacy leakage, destructive behavior, or release-package contamination. Do not disclose exploitable details or private research material in a public issue.

Include the affected version, component, minimal synthetic reproducer, impact, and any safe mitigation. Maintainers should acknowledge the report, preserve evidence privately, assess downstream copies, and publish a coordinated fix and release note when warranted.

The suite consists primarily of instructions and local validation tools. Implicit Skill invocation never grants authority to publish, delete, overwrite, transmit private content, or bypass the host product's approval and sandbox controls.
