# Privacy Policy

Last updated: 2026-10-21

## Scope

This policy covers Research Skills Suite as distributed from its official repository and any separately published derived package. The suite contains agent instructions, templates, and local standard-library validation tools. It does not operate an account service, hosted API, analytics endpoint, advertising system, or telemetry collector.

## Data Handling

The suite itself does not intentionally transmit prompts, files, research data, credentials, or validation results to the maintainer. Its bundled Python tools operate on paths selected by the user or host agent and do not contain network clients. They are designed to validate or transform local project artifacts within the permissions granted by the host environment.

Codex, an installed connector, an external search or database tool, a cloud storage service, or another capability composed with these Skills may process data under its own privacy terms. Research Skills Suite does not control those services. Users should review the active tool set, permissions, and project rules before providing sensitive, confidential, unpublished, personal, or regulated material.

The Skills instruct agents to keep secrets and reversible individual-level data out of prose memory and public examples, to preserve private/public boundaries, and to require explicit authority for publication, cloud synchronization, background monitoring, or writes outside the current scope. These instructions reduce risk but do not replace the host product's sandbox, approval controls, or the user's access-control obligations.

## Public Reports

Support requests and public issue reports are visible to others. Do not include private research data, unpublished documents, credentials, personal paths, proprietary full texts, or identifiable participant records. Use a synthetic reproducer where possible. Report suspected security or privacy vulnerabilities through the private channel described in [SECURITY.md](SECURITY.md).

## Changes and Contact

Material policy changes will be recorded in the repository history and release notes. Use the support route identified in [SUPPORT.md](SUPPORT.md) for privacy questions that do not contain sensitive information.
